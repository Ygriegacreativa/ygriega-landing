# YGRIEGA — Landing (versión para revisión de cliente)

Página estática de un solo archivo (`index.html`). Fuentes y logos van embebidos, así que no necesita servidor ni conexión externa.

## Ver la página
- Abre `index.html` en cualquier navegador, o
- Activa GitHub Pages: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
